# Demon — HTML & CSS Third Project

A responsive multi-section website template built with **pure HTML5 and CSS3** — no frameworks, no JavaScript. Third and most advanced practice project in a series of three.

## Sections

- Header with a **mega menu**
- Articles
- Gallery
- Features
- Testimonials, services, our skills, work steps, videos, events, pricing, team, stats, and a discount section

## Tech Stack

- HTML5 (semantic markup)
- CSS3 (Flexbox / Grid, animations, media queries)
- [Normalize.css](https://necolas.github.io/normalize.css/) for cross-browser defaults
- Font Awesome icons
- Google Fonts (Cairo)

## Run it

No build step needed:

```bash
git clone https://github.com/Dr-Demon-M/Html_css_third_project.git
cd Html_css_third_project
```

Then open `index.html` in a browser — or serve it with any static server (e.g. VS Code **Live Server**).
